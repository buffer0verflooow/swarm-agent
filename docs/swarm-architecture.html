蜂群 Agent 知识系统

基于 Stigmergy 间接协调模式的蜂群智能体架构 — Agent 通过共享 SQLite 知识库自然涌现协作， 不直接通信，不自上而下调度
系统状态: 全部功能已实现 代码: 4,808 行 Python 存储: 25 张 SQLite 表 知识: 37 条 (L1-L4)
01 / DESIGN PHILOSOPHY
为什么用 Stigmergy，不用 Hierarchical
探索型安全任务（漏洞挖掘）的搜索空间不可预分解。Hierarchical 需要 supervisor 提前知道任务分解才能分配—— 但你不知道会找到什么。Stigmergic 模式让 agent 通过 KB 信号自然协调：发现漏洞 → capture → 自动触发 spawn exploiter。
Hierarchical — 不适合

需要预知分解

Supervisor 必须在任务开始前知道完整的子任务列表。探索型任务无法满足：发现一个漏洞才知道下一步该干什么。每次分支都需要回到 supervisor 重新规划。

Stigmergic — 适合

涌现式协调

Agent 不直接通信，而是通过共享环境（SQLite KB）留下信号。其他 agent 轮询检测信号并响应。自然异步、高可扩展、无单点控制。来自生物学：蚂蚁通过信息素间接协作。

混合模式 — 实际实现

集中规划 + 并行执行

执行可以并行（多个 agent 独立探索），但需要全局信息的决策（预算分配、链深控制）由 Orchestrator 集中处理。这是 AWS Security Agent 的实际架构。

01 — 生物学

Stigmergy 间接协调

Agent 不直接通信，通过 SQLite 信号表留下"痕迹"（spawn_requests），其他 agent 轮询响应。 来自 Grassé (1959) 的白蚁筑巢理论。异步、可恢复、无单点。 

# Agent 端
request_spawn(db, run_id,
  requested_role="exploiter",
  chain_depth=1)

# Orchestrator 端 (5s轮询)
pending = poll_spawn_requests(db)
02 — 知识工程

DIKW 金字塔提升

知识自动从 L1(Data) → L2(Info) → L3(Knowledge) → L4(Wisdom) 提升。 提升条件：corroborating sources 数 + trust_vector 置信度。 已验证 L1→L2 提升工作

提升corroboratingtrust
L1→L2≥1≥0.60
L2→L3≥2≥0.75
L3→L4≥3≥0.85
03 — ACOFuzz

信息素蒸发

每条知识有 pheromone (0.0~1.0)。长时间未验证 → 指数衰减 (×0.95^intervals)。 低于 0.1 → 标记 stale，让 agent 去别处探索。验证时 boost 回 1.0。 新增 解决了"死知识"堆积问题 

# 衰减公式
intervals = hours_elapsed / 6
new_phero = old_phero * (0.95 ** intervals)

# 验证时重置
boost_pheromone(db, entry_id, 0.3)
04 — AFLFast

Power Schedule 预算调度

借鉴 AFLFast 的能量调度：根据预算消耗和漏洞密度动态切换策略。 新增 Orchestrator 从 janitor 变成 planner

条件策略
预算 <30%breadth (广撒网)
预算 30-70%balanced
预算 >70%depth (深挖)
漏洞密度 >15%强制 depth
chain > max拒绝 spawn

08 — 独立验证

验证 Pipeline (Unwritable Verifier)

vulnerability 类型自动入验证队列。三重检查: 交叉验证(lineage≥2源) + 反例计数 + 可验证特征(IP/CVE/URL/工具输出)。 confirmed → boost pheromone, refuted → trust 下降 + counter_example。 新增 

# Orchestrator 60s tick
auto_enqueue_validations(db)
process_validation_queue(db)
# score ≥ 3 → confirmed
# score < 0 → refuted
09 — 语义聚类 + 本体发现

TF-IDF 聚类 + 关系发现

TF-IDF 余弦相似度替代纯 tag Jaccard: 28 条知识 → 575 词表 → 93 链接 (vs tag 11 链接)。 本体关系从 tag 共现自动推断: tool+technique→implements 等 7 种规则。 新增 

# TF-IDF: 纯Python, 无外部依赖
tfidf = TF(词频) × IDF(逆文档频率)
sim = cosine(vec_a, vec_b)
# 共现 ≥ 2 → 推断关系
