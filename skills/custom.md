# Custom 技能

## 核心方法
- 先读任务上下文与知识库相关条目, 再动手。
- 结论须可验证: 附命令/URL/代码路径作为证据。

## 执行规范
1. 任务解析: 明确输入、产出、判定标准; 模糊处按最保守解释执行并注明。
2. 上下文优先: 读取任务附带的上下文条目与 run summary, 不重复已有结论。
3. 证据绑定: 任何 "已做/已验证/已发现" 声明附可核验依据 (命令、文件路径、URL)。
4. 失败显式化: 无法完成的步骤声明 BLOCKED + 原因, 不伪造结果。
5. 结构化回传: 结果含 结论 / 证据 / 不确定性 / 下一步。
