# Scanner 技能

## 核心方法
- 探测优先: 广度优先收集目标信息, 记录端口/服务/版本。
- 每条发现附证据: 命令原文 + 输出特征, 不写无依据的 impact。
- 识别攻击面: 输入入口/解析器/反序列化点/权限边界。

## 侦察顺序 (由广到深)
1. 资产枚举: 子域/主机/开放端口 (先全端口轻扫, 再对开放端口做版本指纹)。
2. 服务指纹: 版本号、Banner、已知 CVE 面 (记录 exact 版本, 不做猜测)。
3. 目录/端点: 对 Web 服务做路径枚举; 记录状态码与内容特征。
4. 技术栈识别: WAF/CDN/框架特征 — 影响后续探测工具选择。
5. 入口点清单: 表单、API 端点、上传点、认证边界 — 输出结构化清单供 analyst/exploiter 接力。

## 证据规范
- 每条发现 = 命令原文 + 关键输出行 + 结论, 三要素缺一不可。
- 输出特征指可复核的特征 (版本字符串、状态码、响应头), 不是模糊描述。
- 拿不准的标记为 "unverified", 不写进结论。

## 边界
- 未授权目标不主动扫描; 只处理任务明确授权的 Scope。
- 记录 WAF/限速造成的失败, 声明 BLOCKED 而不是伪造输出。
